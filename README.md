# CPH26: Kodaň 13.–16. 11. 2026

Statická webová stránka s itinerářem rodinného výletu do Kodaně (2 dospělí + 2 děti). Obsahuje dopravu, ubytování, MHD, atrakce s fotkami a mapou a interaktivní rozpočet.

- `index.html`: struktura stránky a statické sekce (doprava, ubytování, MHD, checklist)
- `data.js`: atrakce, itinerář po dnech a položky rozpočtu. **Ceny a časy se upravují tady.**
- `app.js`: vykreslení karet, mapy (Leaflet + OpenStreetMap) a výpočet rozpočtu
- `style.css`: vzhled

Publikace: GitHub → Settings → Pages → Deploy from branch `main` / root. Stránka pak poběží na `https://silajiri.github.io/CPH26/`.
